# Roadmap del Proyecto

Este roadmap describe la evolución planificada del proyecto desde el MVP inicial hasta posibles iteraciones futuras. Su objetivo es **servir como guía**, no como contrato rígido. Las prioridades pueden ajustarse conforme se validen decisiones técnicas y de producto.

---

## 🧪 Fase 0 — Fundaciones técnicas (MVP inicial)

**Estado:** 🟡 En progreso

Objetivo: establecer una base sólida y mantenible sobre la cual construir el producto.

### Alcances

* [x] Inicialización del proyecto
* [x] Configuración base de Spring Boot
* [x] Arquitectura en capas
* [ ] Seguridad stateless con JWT
* [ ] Gestión básica de usuarios
* [x] Endpoints iniciales para clientes
* [ ] Validaciones de entrada
* [ ] Manejo de errores estandarizado
* [ ] Cobertura mínima de tests

---

## 🚀 Fase 1 — MVP funcional (v0.1.x)

**Estado:** ⏳ Planeado

Objetivo: contar con un MVP técnicamente funcional que represente el flujo básico de facturación.

### Alcances

* [ ] Modelo básico de comprobante electrónico
* [ ] Creación y persistencia de facturas
* [ ] Relación cliente–factura
* [ ] Estados básicos del comprobante
* [ ] Documentación mínima de endpoints
* [ ] Versionado inicial de la API

Entregable clave:

* **Release v0.1.0**

---

## 🔄 Fase 2 — Estabilización y calidad (v0.2.x)

**Estado:** ⏳ Planeado

Objetivo: mejorar la calidad del código y la confiabilidad del sistema.

### Alcances

* [ ] Refactor de servicios críticos
* [ ] Aumento de cobertura de tests
* [ ] Tests de integración
* [ ] Mejoras en seguridad
* [ ] Manejo de errores más robusto
* [ ] Documentación técnica ampliada

---

## 🔌 Fase 3 — Integraciones fiscales (post-MVP)

**Estado:** 🔒 Fuera del alcance actual

Objetivo: comenzar la integración con el ecosistema fiscal costarricense.

### Alcances

* [ ] Comunicación con Hacienda
* [ ] Firma digital de comprobantes
* [ ] Recepción de estados
* [ ] Manejo de rechazos

> ⚠️ Esta fase **no forma parte del MVP** y solo se abordará una vez validada la base técnica.

---

## 🌱 Fase 4 — Evolución del producto

**Estado:** 🔒 Fuera del alcance actual

Ideas a explorar en el futuro:

* Gestión multi-empresa
* Panel administrativo
* Roles y permisos avanzados
* Exposición pública de la API
* Posible frontend

---

## 📌 Notas finales

* El roadmap es un documento vivo.
* Las fases anteriores existen para **orientar decisiones actuales**, no para comprometer desarrollo.
* El foco principal es construir un MVP bien diseñado y documentado.
