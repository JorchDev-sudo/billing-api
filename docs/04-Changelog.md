# Changelog del Proyecto

Este documento registra los cambios relevantes del proyecto a lo largo del tiempo. Sigue un enfoque inspirado en **Keep a Changelog** y **Semantic Versioning**, adaptado al contexto de un MVP.

El objetivo no es documentar cada commit, sino **marcar hitos claros** en la evolución del proyecto.

---

## [0.1.0-docs] — Base documental del MVP

**Fecha:** 2026-02-05

### Added

* README.md con descripción general del proyecto
* Documento de visión del producto
* Roadmap con fases del MVP y futuras iteraciones
* Definición explícita del alcance del MVP
* Documentación de la arquitectura del sistema
* Registro de decisiones técnicas

### Purpose

Establecer una base documental sólida que describa el **qué, por qué, cómo y hasta dónde** del MVP antes de avanzar con más funcionalidades.
